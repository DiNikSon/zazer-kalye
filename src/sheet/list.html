Характеристики
Резервная копия
«Экспорт» сохраняет всех персонажей в файл .json. «Импорт» добавляет персонажей из такого файла; с тем же персонажем — заменяет его.
«Печать» — PDF текущего персонажа, «Печать всех» — один PDF со всеми, по две страницы А4 на каждого. Для двусторонней печати переворачивайте по длинному краю.
