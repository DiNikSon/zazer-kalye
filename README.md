# Зазеркалье

Материалы для настольной кампании по видеосериалу «Зазеркалье», собранные в один сайт:

- **Атлас** — граф мира: персонажи, виды, места, предметы и силы, карточки зазеркальцев, текст выпусков;
- **Свод правил** — правила, шпаргалки и распечатки;
- **Лист путника** — лист персонажа с PDF и резервной копией;
- **Тест характеристик** и **Тест навыков** — создание персонажа.
- **Кампания** — материалы ведущего; на входе предупреждение для игроков.

Сайт собирается и выкладывается на GitHub Pages автоматически при каждом пуше в `main`.

## Что где лежит

```
src/
  atlas/shell.html     вёрстка и логика атласа (данные подставляются на место /*DATA*/)
  atlas/data.js        узлы NODES и связи EDGES
  atlas/npc.txt        карточки зазеркальцев (свой формат, см. начало файла и tools/npc_parse.py)
  atlas/img/           картинки узлов (.webp, имя = id узла)
  atlas/map/           карта Артёма (karta.webp) и spots.txt — кликабельные места на ней
  texts/               текст выпусков по абзацам: paras.json (как в видео), paras_clean.json (выправленный)
  rules/rules.html     свод правил (данные атласа подставляются на место /*ATLASDATA*/)
  sheet/list.html      лист путника
  campaign/            кампания «Поиск „пацаноида“»: campaign.js — статьи (движок свода правил;
                       [[id]] — статья кампании, {{id|текст}} — атлас, ((id|текст)) — свод правил),
                       gate.html — предупреждение «владения ведущего» на входе
  tests/               тесты характеристик и навыков
tools/
  build.py             src → build/*.html (самостоятельные страницы) + проверка карточек
  bundle.mjs           build → dist/ (один сайт: вкладки, обфускация, сжатие)
  bridge.js            мост внутри каждого приложения: переходы между вкладками и адреса
  shell/               оболочка сайта (index.html и загрузчик)
  npc_parse.py         разбор и проверка npc.txt
  split.py merge.py swap.py   правка нумерации абзацев с пересчётом ссылок
```

## Сборка у себя

Нужны Python 3 и Node.js 20+.

```sh
npm ci
npm run build          # build/ и dist/
npm run serve          # http://localhost:8080
node tools/bundle.mjs --fast   # dist-fast/ без обфускации — для отладки
```

`build/*.html` открываются и по отдельности — это те же страницы, что и артефакты в Claude.

## Как устроен сайт

`dist/index.html` — оболочка со вкладками. Каждое приложение лежит в `dist/a/<hash>.bin`:
HTML минифицирован, логика обфусцирована, всё сжато gzip и замаскировано. Файл грузится,
когда вкладку открывают впервые, и показывается во встроенном фрейме. Данные (узлы, карточки,
тексты) не обфусцируются, только сжимаются.

Адреса: `#atlas/<id>` — карточка, `#atlas/p<N>` — абзац выпусков, `#rules/<id>` — статья,
`#sheet`, `#stats`, `#skills`. Параметр `?solo` прячет шапку со вкладками (`…/?solo#stats`) — такую ссылку
удобно отправлять игрокам; на вкладках тестов её ставит кнопка «Скрыть шапку». Ссылки на артефакты Claude внутри страниц сборка заменяет на
переходы между вкладками (таблица `LINKS` в `tools/bundle.mjs`).

Лист путника хранит персонажей в `localStorage` браузера (ключ `zz-chars`), поэтому на сайте
они свои, отдельные от артефакта в Claude. Перенести — экспорт/импорт резервной копии в листе.

## Первая публикация

В настройках репозитория: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
Дальше каждый пуш в `main` запускает workflow «Сайт на GitHub Pages»; его можно запустить и
вручную во вкладке Actions.
